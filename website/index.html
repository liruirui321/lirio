常见问题

¥99 Lirio Pro · 永久版包含哪些权益？会按月续费吗？

不会按月续费。¥99 为个人账号绑定的永久版激活码（1 码限 1 人，最多同时登录 3 台个人设备），兑换后永久解锁全部本地精听、听写、音频自动切分、自定义 API Key 与应用内提需求通道，并赠送 ¥10 AI 对话加油包。

为什么你们不卖高价 AI 年卡，而用卡密按量计费？

因为语言学习 90% 的时间都在本地听音频和打字练习。只在你开启 AI 口语考官、地道复盘和错因诊断时消耗 DeepSeek Token，¥10 余额足够大多数同学备考 1–2 个月。

用户在客户端会拿到服务端的 DeepSeek API Key 吗？

不会。DeepSeek 主 Key 仅保存在服务端环境变量中，客户端只持有你个人的登录 JWT 令牌并通过服务端按量扣费代理调用。

目前 iPhone 怎么用？

iOS 因苹果签名政策要求正在筹备 TestFlight 公测通道；在此之前，iPhone 可通过 Safari 访问部署后的响应式网页端直接练词汇和口语复盘，或先使用 Mac / Windows / Android 原生端。
