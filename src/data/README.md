Pronunciation data derives from CMU Pronouncing Dictionary (https://github.com/cmusphinx/cmudict), downloaded 2026-10-23. `pronunciations.json` retains the first dictionary pronunciation per word and strips stress digits. The CMU license is retained in CMUDICT-LICENSE.txt and displayed in the analysis screen in bundled builds. This American-English dictionary supplies phoneme boundaries, not an acoustic diagnosis of the user's British/other-accent recording.

Teaching references: British Council, Connected speech (https://www.teachingenglish.org.uk/professional-development/teachers/teaching-knowledge-database/c/connected-speech), Weak forms (https://www.teachingenglish.org.uk/professional-development/teachers/teaching-knowledge-database/t-w/weak-forms). These rules generate possible causes only; they do not infer vocabulary knowledge or claim the original speaker used a particular reduction.
